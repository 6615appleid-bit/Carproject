## 首次提交与上传

在工程根目录执行以下命令，先检查待提交文件：

```powershell
git status --short
git add .
git diff --cached --stat
git commit -m "Initial commit"
git push -u origin main
```

提交需要已配置 Git 用户名和邮箱，上传需要具有该仓库写权限的 GitHub 登录凭据。
